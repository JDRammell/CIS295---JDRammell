🚀 Scroll-Driven Animations

Internal Documentation for Junior Developers

📖 What & Why

Scroll-driven animations are a modern CSS feature that allows elements to animate based on scroll position, rather than time. Instead of using JavaScript to detect scroll events and trigger animations manually, we can now use pure CSS with the animation-timeline: view() property.

Why use this instead of the old way? Previously, we'd write JavaScript like this: 

// Old way: JavaScript scroll listeners (performance issues!)
window.addEventListener('scroll', () => {
    const elements = document.querySelectorAll('.card');
    elements.forEach(el => {
        if (isInViewport(el)) {
            el.classList.add('visible');
        }
    });
});

This approach has problems: it runs on every scroll event (causing performance issues), requires extra JavaScript, and is harder to maintain. The new CSS approach is simpler and eliminates the need for scroll event listeners entirely.

💻 The Code

Here's how to implement scroll-driven animations in pure CSS:

/* Step 1: Define your animation keyframes */
@keyframes fade-slide-up {
    from {
        opacity: 0;
        transform: translateY(50px);
    }
    to {
        opacity: 1;
        transform: translateY(0);
    }
}

/* Step 2: Apply to your element */
.card {
    animation: fade-slide-up linear;
    animation-timeline: view();
    animation-range: entry 0% cover 40%;
}

What each property does:

  • animation: fade-slide-up linear; Uses your keyframes with linear timing
  • animation-timeline: view(); THE KEY PROPERTY | links animation to scroll position
  • animation-range: entry 0% cover 40%; Controls when animation happens (starts when element enters viewport, completes at 40% visibility)

⚠️ Gotchas & Browser Support

Browser Support: This feature is cutting-edge! As of 2024, it's supported in Chrome 115+, Edge 115+, and Safari 17.5+. Firefox support is in progress.

Always include a fallback:

/* Ensure elements are visible by default */
.card {
    opacity: 1;
}

/* Only apply scroll animation if supported */
@supports (animation-timeline: view()) {
    .card {
        animation: fade-slide-up linear;
        animation-timeline: view();
        animation-range: entry 0% cover 40%;
    }
}

Common mistake: Forgetting the animation-range property. Without it, the animation timing won't work as expected!
